# Development roadmap

## Milestone 0 — feasibility
- [ ] Confirm Windows 11 and target iOS compatibility.
- [ ] Review current upstream UxPlay release, license, vulnerabilities, and dependencies.
- [ ] Reproduce an upstream build and local iPhone mirroring.

## Milestone 1 — first usable receiver
- [ ] Define process control and connection status flow.
- [ ] Enforce PIN pairing in default configuration.
- [ ] Make firewall exposure private-network-only.
- [ ] Display video in a resizable Windows window.
- [ ] Play synchronized audio.

## Milestone 2 — native UI
- [ ] Windows 11 visual shell.
- [ ] Fullscreen, always-on-top, and disconnect controls.
- [ ] Connection status and actionable error handling.

## Milestone 3 — security and distribution
- [ ] Audit dependency versions and known CVEs.
- [ ] Record build provenance and package checksums.
- [ ] Validate clean uninstall and firewall-rule cleanup.
- [ ] Document GPL obligations, code notices, and any distribution constraints.
